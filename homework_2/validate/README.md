# Validate

Функция `validate_stack_sequences(pushed, popped)` возвращает `True`, если
извлечения из стека могут идти в порядке `popped`, а добавления — в порядке
`pushed`. По условию значения уникальны, а `popped` — перестановка `pushed`.
Исходные списки не изменяются.

## Идея решения

Симулируем стек обычным списком. По очереди добавляем значения из `pushed`.
После каждого добавления снимаем с вершины все элементы, которые совпадают
со следующими ожидаемыми значениями из `popped`. Индекс `next_pop` показывает,
сколько извлечений уже выполнено. В конце возвращаем `True`, если стек пуст.

Если вершина совпадает с очередным ожидаемым значением, её можно снять сразу:
другой элемент раньше неё извлекать нельзя. Если вершина не совпадает,
извлечение запрещено и остаётся добавлять следующие элементы из `pushed`.
Поэтому алгоритм не пропускает возможное решение. Если после всех добавлений
стек не пуст, нужный элемент закрыт другими, а допустимых операций больше нет.

## Пример

`pushed = [1, 2, 3, 4, 5]`, `popped = [1, 3, 5, 4, 2]`.
Вершина стека в таблице находится справа.

| Шаг | Операции | Стек после операций | Выполнено извлечений |
| --- | --- | --- | --- |
| 1 | `push(1)`, `pop(1)` | `[]` | 1 |
| 2 | `push(2)` | `[2]` | 1 |
| 3 | `push(3)`, `pop(3)` | `[2]` | 2 |
| 4 | `push(4)` | `[2, 4]` | 2 |
| 5 | `push(5)`, `pop(5)`, `pop(4)`, `pop(2)` | `[]` | 5 |

Стек пуст, ответ — `True`.

## Сложность

- Время — **O(n)**: каждый элемент добавляется один раз и извлекается не более
  одного раза. Вложенный `while` суммарно выполняет не более `n` извлечений.
- Дополнительная память — **O(n)**: в худшем случае стек содержит все `n`
  элементов, например при обратном порядке извлечения.

## Тесты

Проверяются примеры из условия, один элемент, прямой и обратный порядок,
чередование операций, невозможный порядок после корректного начала,
отрицательные значения и ноль, сохранность входных списков и длина 100 000.
Сторонние библиотеки не нужны.

Запуск из корня репозитория:

```bash
python3 -B -m unittest discover -s homework_2/validate -v
```
