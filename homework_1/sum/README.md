# Максимальная чётная сумма

Нужно выбрать элементы массива положительных целых чисел так, чтобы их сумма
была максимальной и делилась на 2.

## Идея

В одном цикле считаем сумму всех чисел и ищем минимальное нечётное.
Если общая сумма чётная, возвращаем её. Иначе вычитаем минимальное нечётное.

Все числа положительные, поэтому выгодно взять их все. Если сумма нечётная,
нужно убрать нечётную сумму. В ней обязательно будет хотя бы одно нечётное
число, а остальные положительные слагаемые только увеличат потерю.
Поэтому достаточно убрать минимальное нечётное число.

## Сложность

Пусть `n` — количество элементов. Время — `O(n)`: один проход по массиву.
Дополнительная память функции — `O(1)`:
храним сумму и минимум. Считаем арифметические операции за `O(1)`.
Чтение ввода через `split()` отдельно требует `O(n)` памяти для чисел фиксированной длины.

## Пример

Вход: `7 2 5 8 3`. Сначала `total = 0`, `min_odd = -1`.

| Число | Сумма | Минимальное нечётное |
| --- | --- | --- |
| 7 | 7 | 7 |
| 2 | 9 | 7 |
| 5 | 14 | 5 |
| 8 | 22 | 5 |
| 3 | 25 | 3 |

Сумма `25` нечётная. Убираем `3`, получаем ответ `22`.

## Тесты

В `test_sum.py` проверяются одиночные числа, только чётные числа, чётная
и нечётная общая сумма, повторения и разное положение минимального нечётного.
Для одного нечётного числа выбираем пустой набор с суммой `0`.

Запуск из этой папки:

```bash
python3 -m unittest -v test_sum.py
```
