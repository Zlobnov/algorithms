# Количество простых чисел

Нужно посчитать простые числа, которые строго меньше `N`.

## Идея

Если `N <= 2`, ответ равен `0`. Иначе создаём список чисел от `0` до `N - 1`.
Ноль и единицу не считаем простыми.

Идём от двойки. Если число ещё не вычеркнуто, заменяем его кратные нулями,
начиная с квадрата этого числа. Меньшие кратные уже обработаны раньше.
В конце считаем оставшиеся ненулевые элементы.

У любого составного числа есть простой делитель не больше его квадратного корня.
Поэтому достаточно идти, пока `pointer * pointer < N`: все составные числа
будут вычеркнуты, а простые останутся.

## Сложность

Время — `O(N log log N)`: для каждого простого `p` вычёркиваем примерно `N / p`
чисел, и сумма этой работы по простым даёт такую оценку.
Память — `O(N)` для списка. Арифметические операции считаем за `O(1)`.

## Пример

Для `N = 20` сначала остаются числа от `2` до `19`.

| `pointer` | Действие |
| --- | --- |
| 2 | Вычёркиваем `4, 6, 8, 10, 12, 14, 16, 18` |
| 3 | Вычёркиваем `9, 12, 15, 18` |
| 4 | Уже вычеркнуто, пропускаем |

Дальше `5 * 5 >= 20`, цикл заканчивается.
Остались `2, 3, 5, 7, 11, 13, 17, 19`. Ответ — `8`.

## Тесты

В `test_prime.py` проверяются отрицательные числа, `0`, `1`, `2`, небольшие
и большие значения, квадраты простых чисел и граница `< N`.

Запуск из этой папки:

```bash
python3 -m unittest -v test_prime.py
```
