# Палиндром

Проверяем, является ли положительное целое число палиндромом, без использования строк.

## Идея

Через `% 10` получаем последнюю цифру, а через `// 10` убираем её из числа.
Так собираем все цифры в список в обратном порядке.

Сравниваем цифры с двух концов списка, двигаясь к середине. Если нашлась
разная пара — возвращаем `False`, иначе `True`. У палиндрома все такие пары
совпадают. Среднюю цифру при нечётной длине проверять не нужно.

## Сложность

Пусть `d` — количество цифр. Время — `O(d)`: извлекаем все цифры и сравниваем
не больше `d // 2` пар. Здесь считаем арифметические операции за `O(1)`.
Память — `O(d)`, так как храним список цифр.

## Пример

Для числа `123421` список заполняется так:

| Оставшееся число | Список цифр |
| --- | --- |
| 12342 | `[1]` |
| 1234 | `[1, 2]` |
| 123 | `[1, 2, 4]` |
| 12 | `[1, 2, 4, 3]` |
| 1 | `[1, 2, 4, 3, 2]` |
| 0 | `[1, 2, 4, 3, 2, 1]` |

Крайние цифры совпали: `1 == 1`. В цикле сравниваем пары:
`1 == 1`, `2 == 2`, затем `4 != 3`. Возвращаем `False`.

## Тесты

В `test_palindrom.py` проверяются однозначные числа, палиндромы чётной
и нечётной длины, нули внутри и на конце, несовпадения в середине и большие числа.

Запуск из этой папки:

```bash
python3 -m unittest -v test_palindrom.py
```
