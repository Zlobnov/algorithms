# Anagrams

Дан список слов. Нужно сгруппировать все анаграммы — слова, состоящие из
одинаковых символов с одинаковым числом вхождений каждого символа.

Пример:

```text
Вход:  ["eat", "tea", "tan", "ate", "nat", "bat"]
Ответ: [["bat"], ["nat", "tan"], ["ate", "eat", "tea"]]
```

Порядок групп и слов в ответе в условии не задан.

Решение должно включать код, объяснение, обоснование сложности по времени и
памяти, пошаговую визуализацию нетривиального примера и тесты.
