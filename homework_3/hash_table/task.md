# Создание хеш-таблицы

Реализовать собственную хеш-таблицу для хранения пар «ключ–значение» с операциями вставки, поиска по ключу и удаления.

Продумать хранение данных, разрешение коллизий и поведение при заполнении таблицы. Для хранения данных можно использовать только `list`.

Задание творческое: конкретный способ разрешения коллизий и интерфейс операций не заданы.

Источник: [домашнее задание №3, задача 3](https://stepik.org/lesson/2612928/step/2?unit=2652766).
