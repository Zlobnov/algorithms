# Two Sum

Функция `two_sum(arr, k)` возвращает кортеж из двух индексов по возрастанию. По условию подходящая пара существует и единственна. Массив не изменяется.

## Идея решения

Идём по массиву слева направо. В словаре `seen` храним уже встреченные числа и их индексы. Для текущего числа `value` ищем дополнение `k - value`. Если оно есть в словаре, возвращаем его индекс и текущий индекс. Иначе запоминаем текущее число.

Поиск выполняется **до добавления** текущего элемента: так один индекс не может использоваться дважды. Два одинаковых числа на разных позициях подходят, например `[5, 5]` при `k = 10`.

Перед каждой итерацией словарь содержит числа только из уже просмотренной части массива. Поэтому найденные индексы различны, идут по возрастанию, а сумма равна `k`. Когда дойдём до второго элемента искомой пары, первый уже будет в словаре. Если постороннее число повторится, его индекс в словаре просто обновится — для поиска дополнения достаточно любой предыдущей позиции. Цикл выполнит не более `n` шагов, поэтому завершится.

## Пошаговый пример

`arr = [8, -3, 4, 8, 6, 2]`, `k = 3`. Запись `8: 0` означает «число 8 встретилось на позиции 0».

| Индекс | Число | Ищем | seen перед шагом | Действие |
| --- | --- | --- | --- | --- |
| 0 | 8 | -5 | `{}` | Добавить `8: 0` |
| 1 | -3 | 6 | `{8: 0}` | Добавить `-3: 1` |
| 2 | 4 | -1 | `{8: 0, -3: 1}` | Добавить `4: 2` |
| 3 | 8 | -5 | `{8: 0, -3: 1, 4: 2}` | Обновить `8: 3` |
| 4 | 6 | -3 | `{8: 3, -3: 1, 4: 2}` | Найти `-3` на позиции 1, вернуть `(1, 4)` |

Вывод: `1 4`, потому что `arr[1] + arr[4] = -3 + 6 = 3`. Последний элемент просматривать уже не нужно.

## Сложность

Пусть `n` — длина массива. При обычном распределении хешей операции словаря занимают ожидаемое **O(1)** время; расширения таблицы учитываются амортизированно. Обходим массив один раз, поэтому ожидаемое время решения — **O(n)**. При большом числе коллизий одна операция словаря может потребовать **O(n)**, а весь алгоритм в худшем случае — **O(n²)**.

Дополнительная память — **O(n)**: словарь хранит не более `n` чисел и индексов. Память ответа — **O(1)**, рекурсии нет. Оценки используют стандартное предположение, что арифметика, хеширование и сравнение одного целого числа занимают O(1); для произвольно больших чисел стоимость зависит и от их разрядности.

## Запуск и тесты

Запуск из корня репозитория:

```bash
python3 homework_3/two_sum/source_two_sum.py
python3 -B -m unittest discover -s homework_3/two_sum -v
```

Первый запуск выводит `1 2` для первого примера условия. Для других данных можно вызвать `print(*two_sum(arr, k))`.

Тесты покрывают оба примера, минимальную длину, запрет повторного использования одного элемента, одинаковые значения на разных позициях, отрицательные числа, нули, повторы посторонних чисел, ответ в конце массива, большие числа и длинный массив. Проверяется также сохранность входа и формат вывода.

Отдельный тест перебирает все массивы длины от 2 до 5 со значениями от -2 до 2 и суммы от -4 до 4. Независимый перебор всех пар находит эталон; с ним сравнивается результат для каждого случая с единственной подходящей парой.
